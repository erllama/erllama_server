# erllama_server has moved

`erllama_server` is now **Barrel Inference Server**, developed in the
`barrel-platform` monorepo.

- New home: https://github.com/barrel-platform/barrel_inference
- This server: https://github.com/barrel-platform/barrel_inference/tree/main/apps/barrel_inference_server

The OpenAI-, Anthropic-, and Ollama-compatible HTTP daemon continues there as
the `barrel_inference_server` package; the CLI is now `barrel-inference`. This
repository is archived and read-only; its full history is preserved in the
monorepo under `apps/barrel_inference_server/`.
